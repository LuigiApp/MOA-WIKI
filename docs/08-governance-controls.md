# 08 – Governance & Controls

## Obiettivo della fase

Definire per ogni use case il livello di approvazione e i controlli richiesti,in funzione della classe di rischio.

## Campi da compilare

| Campo | Significato | Esempio |
| --- | --- | --- |
| Use Case ID | Collegamento allo use case. | UC-023 |
| Risk Class | Classe di rischio derivata dall'AI Risk Gate. | Green, Yellow, Orange, Red |
| Livello di Approvazione | Chi deve approvare in funzione della Risk Class. | IT Owner / Steering Committee |
| Governance minima | Set minimo di controlli richiesti. | Review periodica, audit log |
| Organo Decisionale | Persona o organo che formalizza l'approvazione. | Steering Committee AI |
| Controlli richiesti | Controlli specifici generati dalla Risk Class. | Monitoraggio continuo, governance dedicata |

## Riferimento al Calculator

Il foglio Governance & Controls viene compilato dopo l'AI Risk Gate.La Risk Class rappresenta l'input principale per determinare il livello di governance richiesto.

**Regola pratica.**Green = controlli standard;Yellow = validazione IT Owner;Orange = approvazione Steering AI;Red = governance dedicata e monitoraggio continuo.
