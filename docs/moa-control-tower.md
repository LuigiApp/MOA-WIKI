# MOA Control Tower

Secondo layer del framework: governare l'intero ciclo di vita degli agenti AI, dalla decisione di attivarli alla gestione in produzione. Comprende le fasi da 06 a 11.

## Domande a cui deve rispondere

- Quanti use case sono nel portfolio?
- Quali sono prioritari?
- Quali sono in sviluppo?
- Quali agenti sono in produzione?
- Quanto valore generano?
- Quali agenti hanno una Risk Class Orange o Red e richiedono approfondimenti?
- Quali decisioni vanno portate all'AI Steering Committee?
