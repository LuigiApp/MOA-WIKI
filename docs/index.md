# MOA Wiki – Practitioner Guide
Versione V1 — 9 ottobre 2026    


## Scopo

Questo Wiki forma i **MOA Practitioner** nell'utilizzo operativo del framework MOA. L'obiettivo è fornire una guida pratica per raccogliere informazioni dal cliente, trasformare bisogni aziendali in use case agentici, compilare il file MOA e alimentare la MOA Control Tower.

| Elemento | Descrizione |
|---|---|
| Framework | MOA – Agentic Operating Model |
| Scopo | Applicazione operativa del metodo presso clienti |
| Audience | MOA Practitioner |
| Output | Portfolio agentico governato, misurabile e prioritizzato |

Ogni pagina contiene obiettivo, input, attività, campi da compilare, significato dei campi, esempi, output atteso e controlli di qualità.

!!! note "Principio generale"
    Il MOA non è un esercizio documentale: è uno strumento per prendere decisioni migliori su valore, fattibilità, responsabilità, rischio e readiness degli agenti AI.


# Come il Wiki si collega al Calculator
Il Wiki descrive tutte le fasi del metodo. Non tutte le fasi dispongono di un foglio dedicato nel Calculator: alcune si basano su strumenti esterni, altre condividono lo stesso foglio.

| **Fase** | **Strumento di riferimento** |
|---|---|
| 01 Preparazione | Portfolio Maturity Check: file dedicato. Company Context Sheet: non previsto nel Calculator. |
| 02 Demand Generation | AI Opportunity Backlog: non previsto nel Calculator. |
| 03 Use Case Pipeline | Foglio MOA Scoring Calculator, colonne A–L |
| 04 MOA Scoring | Foglio MOA Scoring Calculator, colonne M–V; foglio MOA Matrix |
| 05 Activation | Foglio MOA Scoring Calculator, colonna V; foglio Value Realization per l’indicazione dei responsabili |
| 06 Value Realization | Foglio Value Realization |
| 07 Governance & Controls | Foglio Governance & Controls |
| 08 Process Risk Gate | Foglio Process Risk Gate |
